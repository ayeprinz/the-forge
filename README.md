# the-forge

Daily audio curriculum. One episode a day, rendered by GitHub Actions.

- `scripts/YYYY-MM-DD.json` - the episode script for that date
- `build.py` - renders the day's script to MP3, rebuilds the feed, prunes old audio
- `docs/` - published by GitHub Pages; `docs/feed.xml` is the podcast feed

Feed URL: https://ayeprinz.github.io/the-forge/feed.xml
